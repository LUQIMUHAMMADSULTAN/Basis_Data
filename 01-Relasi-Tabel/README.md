# Praktikum 1 — Relasi Tabel

Praktikum ini membahas pembuatan tabel dan penggunaan **Primary Key** serta **Foreign Key** untuk menghubungkan tabel.

### Tabel

- `matkul` — data mata kuliah
- `dosen` — data dosen
- `nilai` — data nilai dan relasi dengan mata kuliah serta dosen

### Cara Menjalankan

Jalankan file SQL melalui MySQL Shell:

```text
\source C:/lokasi-folder/Tugas_Praktikum_Basis_Data_Relasi.sql
```

Ganti alamat file sesuai lokasi penyimpanan di komputer.
