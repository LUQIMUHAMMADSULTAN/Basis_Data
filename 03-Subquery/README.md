# Praktikum 3 — Subquery

Praktikum ini membahas penggunaan subquery pada SQL untuk mengambil dan menyaring data berdasarkan hasil query lain.

### Materi

- `SELECT` untuk menampilkan data
- `Subquery` untuk menjalankan query di dalam query lain
- `IN` dan `NOT IN` untuk memilih atau mengecualikan data
- `WHERE` untuk menyaring data berdasarkan kondisi

### Cara Menjalankan

Jalankan file SQL melalui MySQL Shell:

```text
\source C:/lokasi-folder/NAMA_FILE_SQL.sql
```

Ganti alamat dan nama file sesuai lokasi penyimpanan di komputer.
