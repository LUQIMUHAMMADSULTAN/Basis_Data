# Praktikum 2 — Kondisi Tabel

Praktikum ini membahas penggunaan kondisi pada SQL untuk menentukan keterangan berdasarkan nilai abjad.

### Materi

- `SELECT` untuk menampilkan data
- `CASE` untuk menentukan keterangan
- `IF` bertingkat sebagai alternatif kondisi

### Cara Menjalankan

Jalankan file SQL melalui MySQL Shell:

```text
\source C:/lokasi-folder/NAMA_FILE_SQL.sql
```

Ganti alamat dan nama file sesuai lokasi penyimpanan di komputer.
